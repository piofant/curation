Основная страница показывает, как система выбирает кандидатов до публикации. Настоящая подстраница отражает противоположный угол — фактическую эффективность публикаций после их выхода: каналы-источники, дни недели, часы публикации, платформа и длина текста, давшие наибольший прирост ERR и пересылок.

Каналы-источники по среднему ERR

Каналы, материалы которых после прохождения через систему дают наибольший отклик в @kompege. Порог выборки: n ≥ 3 публикаций.

Средний ERR по дню недели

Распределение вовлечённости по дням; индикатор оптимального окна публикации.

Средний ERR по часу публикации

Распределение по часам московского времени. Полупрозрачные столбцы — часы с малой выборкой (менее трёх публикаций), статистическая надёжность ниже.

Платформа канала-источника

Сравнение Telegram-курации и репостов из ВКонтакте; соответствует результатам Главы 3 ВКР.

Длина текста публикации

Распределение среднего ERR по категориям: короткий / средний / длинный.

Распределение ERR по интервалам

Гистограмма количества публикаций в каждом интервале вовлечённости. Правый хвост распределения — публикации с виральным охватом.

Наиболее виральные публикации

Восемь публикаций с наибольшим числом пересылок (forwards) — прямой индикатор виральности контента в Telegram.

Метрики собраны через библиотеку Telethon из открытых данных Telegram. Подробное описание методики и формул — на основной странице. Открытый исходный код: github.com/piofant/curation.
