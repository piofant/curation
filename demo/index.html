Стадия 3 / 8

Из чего складывается оценка качества (Q)

Качество поста Q — сумма четырёх простых признаков. Чем полезнее пост для аудитории, тем выше Q.

ПризнакЧто смотримУ этого постаБаллы
Виральность доля пересылок от просмотров 14 из 1025 = 1,4 % — обычный уровень +0,10
Сколько раз переслали абсолютное число пересылок 14 пересылок — нормально +0,15
Есть полезная ссылка ссылка на VK / YouTube / материалы да, ссылка на VK +0,15
Учебная лексика слова темы: Python, задание, ЕГЭ… ≈ 3 совпадения +0,08
Итого качество Q 0,48

Ещё раньше, на стадии 1, отсеиваются посты без ссылок, явно рекламные (слова «курс», «скидка», «у нас», «огэ») и слишком короткие. Качество Q считается только для тех, кто прошёл этот фильтр.

Стадия 4 / 8

Финальная формула score

Q со стадии 3, плюс ещё три компонента. Каждый нормализуется на максимум по выборке кандидатов и умножается на свой вес.

score = 0,40·Qnorm + 0,30·Fnorm + 0,20·R + 0,10·Vnorm

Стадия 7 / 8

Корректировка весов

Веса 0,40 / 0,30 / 0,20 / 0,10 подобраны эмпирически под @kompege. Для других ниш и стратегий ручка крутится по-разному:

Когда менятьКуда крутитьПочему
Канал страдает от рекламного спама ↑ Q усилить штрафы по чёрному списку и сигналам образовательного словаря
Виральность главный приоритет ↑ F для каналов-агрегаторов вроде @kompege это и есть основная функция
Новостная ниша — быть первым ↑ R штрафовать всё старше суток сильнее
Растущий канал за счёт охвата ↑ V хайповый контент даже с низким качеством иногда даёт первичный приток

Сейчас веса задаются вручную в коде скоринга и применяются после перезапуска. Автоматическая подстройка по обратной связи от метрик после публикации — направление дальнейшей работы (Заключение ВКР).

Стадия 8 / 8 — итог

Что это значит

  • 1–5 публикаций в день из 200–400 кандидатов — узкое горлышко работает.
  • Время редактора снижено с 8–10 ч/нед до < 1 ч/нед. Эфир канала пополняется без ручного отбора.
  • Все расчёты открыты для верификации: исходники, веса, score каждого поста — на одной странице.
