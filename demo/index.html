Стадия 3 / 8

Внутренности качества (Q)

Что внутри content_quality: оно собирается из четырёх под-компонентов в analytics/content_filter.py:

Под-компонентКак считаетсяТир / ЗначениеВклад
Viral Rate (ER) forwards / views 14/1025 = 1,37 % → tier «обычный (≥ 1 %)» +0,10
Абсолютные пересылки forwards в tier 14 → tier «нормально» (≥ 10, < 15) +0,15
Внешняя ссылка VK / YouTube / docs в тексте есть VK-ссылка +0,15
Образовательные сигналы словарь (Python, задание, ЕГЭ, ...) ≈ 3 совпадения × 0,03 (cap 0,10) +0,08
Итого Q (cap 1,00) 0,48

Хард-фильтр (стадия 1) до этого выкинул посты без внешней ссылки, со словами из чёрного списка («курс», «скидк», «у нас», «огэ»), и слишком короткие (< 50 символов). Q вычисляется только для прошедших.

Стадия 7 / 8

Корректировка весов

Веса 0,40 / 0,30 / 0,20 / 0,10 подобраны эмпирически под @kompege. Для других ниш и стратегий ручка крутится по-разному:

Когда менятьКуда крутитьПочему
Канал страдает от рекламного спама ↑ Q усилить штрафы по чёрному списку и сигналам образовательного словаря
Виральность главный приоритет ↑ F для каналов-агрегаторов вроде @kompege это и есть основная функция
Новостная ниша — быть первым ↑ R штрафовать всё старше суток сильнее
Растущий канал за счёт охвата ↑ V хайповый контент даже с низким качеством иногда даёт первичный приток

Сейчас корректировка ручная: правка констант в analyzer.py + перезапуск пайплайна. Автоматическая подстройка через обратную связь от метрик пост-публикации — направление дальнейшей работы, упомянутое в Заключении ВКР.

Стадия 8 / 8 — итог

Что это значит

  • 1–5 публикаций в день из 200–400 кандидатов — узкое горлышко работает.
  • Время редактора снижено с 8–10 ч/нед до < 1 ч/нед. Эфир канала пополняется без ручного отбора.
  • Все расчёты открыты для верификации: исходники, веса, score каждого поста — на одной странице.
